# KPA_COMPLEX

Историческая база стендовых программ ЯВ/БКД: обмен, диагностический GUI, сетевой proxy и эмуляторы. Предшественник последующего стендового направления; не вся папка собирается как одно приложение.

## Точки входа

| Часть | Назначение |
|---|---|
| Корневой CMake → `src/main.cpp` | `kpa_complex` и подключённые слои `src/` |
| `Yv_with_yls_emulation/` | Отдельный проект; корневой сборкой не подключается |
| `TestYPS_YPS_MODULE_FOR_BKD` | Gitlink на утилиту; `.gitmodules` отсутствует |

Корневая сборка задаёт C++20, Qt6 и Boost; путь Boost фиксирован в CMake под Windows. Сетевой слой использует WinDivert. Сборка и аппаратные режимы в рамках оформления не проверялись.

Полезные режимы сохраняются до проверенной замены. [KPA-BKD-_MVP](https://github.com/Anatolichka2202/KPA-BKD-_MVP) — узкий смежный инструмент; [MilTechStation](https://github.com/Anatolichka2202/KPA-YALK_MODULE) — действующая линия универсального приложения.
